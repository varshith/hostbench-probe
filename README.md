# hostbench-probe

The HostBench controlled test page for GitHub Pages. It is deployed from this repo (not from the
HostBench site repo) so that site rebuilds never change what the probes measure.

Source of truth for the page is `test-page/` in https://github.com/varshith/hostbench. Do not edit
here; copy from there and keep every platform's copy byte-identical.

Live: https://varshith.github.io/hostbench-probe/
